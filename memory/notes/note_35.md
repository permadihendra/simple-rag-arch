# Tool Creation Policy: Ask First

- **Tags**: policy, tool, constraint, critical
- **Created**: 2026-05-18T18:08:54Z
- **Importance**: 5

DO NOT create new RAG tools without asking first. The current tool set (rag_search, rag_note, rag_status, rag_checkpoint, rag_next_step, rag_end_session, rag_configure) is FINAL for now. If something needs improvement, optimize existing tools/commands instead. Always ask the user before building anything new.
